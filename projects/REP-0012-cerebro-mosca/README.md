# Cérebro de mosca · REP-0012

Raiz do FlyBrain, MagLab, executor Node e demonstração da mosca-guia. Acesso canônico: https://pedrocamargolince.github.io/maGbRAIN/cerebro-mosca/.

O jogo submarino (REP-0001) é projeto de PedroCamargoLINCE. Felipe sugeriu a integração da mosca como NPC; isso não torna o laboratório parte do jogo. A relação entre os nós registra somente essa proposta. Créditos técnicos do laboratório são associados a REP-0012.

- `app/`: implementação e recursos.
- `app/sensory-lab/node/README.md`: controles por script e ensaios offline.
- `PLAN.md` e `STATUS.md`: plano e continuidade.
- `DEMO.md`: demonstração experimental, ainda com regras de movimento.

URLs antigas em mosca-guia/ encaminham para este projeto. O checkout local independente flybrain continua disponível; no repositório coletivo a raiz é esta pasta.
